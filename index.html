PayMongo QRPh (automatic)

1) Sign up at paymongo.com and finish business verification for live payments.
2) Dashboard → Developers → API Keys → copy Public key (pk_test_… or pk_live_…).
3) Paste Public key below and Save.
4) Copy Secret key (sk_…) — never put it in this website. In Supabase → Edge Functions → Secrets add:
  PAYMONGO_SECRET_KEY = your sk_…
  WEB3FORMS_KEY = same key as Settings
  STORE_EMAIL = zoraofficial005@gmail.com
5) Deploy functions (from this project folder in Terminal):
  npx supabase login
  npx supabase link --project-ref eulhdzltttehxbyrdqxa
  npx supabase functions deploy create-qrph-payment
  npx supabase functions deploy paymongo-webhook
6) PayMongo → Developers → Webhooks → Add endpoint:
  https://eulhdzltttehxbyrdqxa.supabase.co/functions/v1/paymongo-webhook
  Event: payment.paid
