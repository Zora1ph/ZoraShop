Automatic payments (GCash, PayMaya, Bank Transfer)

Checkout shows those three options. Each one uses PayMongo QRPh, so when the customer pays, the order is marked Paid, Gmail gets the full details, and it is stored in Admin → Orders. You do not mark paid by hand.

1) Sign up at paymongo.com and finish business verification for live payments.
2) Developers → API Keys → paste the Public key below and Save.
3) Put the Secret key only in Supabase → Edge Functions → Secrets:
  PAYMONGO_SECRET_KEY, WEB3FORMS_KEY, STORE_EMAIL = zoraofficial005@gmail.com
4) Deploy create-qrph-payment and paymongo-webhook.
5) PayMongo webhooks → https://eulhdzltttehxbyrdqxa.supabase.co/functions/v1/paymongo-webhook · event payment.paid
